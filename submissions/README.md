# Submissions

Each experiment is a directory under this folder:

```text
submissions/<name>/usr_code.py
submissions/<name>/init_pose.csv
```

`<name>` starts with a letter or digit and may contain letters, digits, `.`, `_`, and `-`.
Open a pull request that adds the directory. Do not push straight to `main`.

`email.txt` is not required. GitHub notifies the pull request author.
The root `usr_code.py` in this repository is leftover from the old queue. It is not a submission.
